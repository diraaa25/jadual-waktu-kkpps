1. Pengenalan Sistem SiJAWAP

SiJAWAP (Sistem Jadual Waktu KKPPS) ialah aplikasi web berasaskan Progressive Web App (PWA) yang direka khas untuk memudahkan penjadualan, semakan kelas, carian pensyarah, pemakluman hebahan, dan cetakan rasmi jadual waktu bagi Kolej Komuniti Papar.

1.1 Portal dan Komponen Utama

Portal / Halaman Fail Sumber Fungsi Utama
Portal Utama index.html Laman pendaratan (*landing page*), gerbang navigasi pantas ke portal Pelajar, Pensyarah, atau Pentadbir, serta paparan hebahan umum terkini.
Portal Pelajar Pelajar.html Membolehkan pelajar menyemak jadual mengikut program dan kelas, melihat waktu rehat, bilik kuliah, serta memuat turun jadual.
Portal Pensyarah Pensyarah.html Carian jadual peribadi pensyarah, semakan kekosongan bilik/makmal, dan pengurusan hebahan program.
Portal Programmer / Admin Programmer.html Pusat kawalan pentadbir: mengurus slot, mengimport data Excel, kawalan sesi, kelulusan jadual, dan pengesanan pertindihan.
Paparan Jadual Terperinci Jadual_baru.html Grid interaktif jadual waktu penuh mengikut hari (Isnin hingga Jumaat) dengan fungsi cetakan berformat rasmi.

1.2 Program Pengajian yang Disokong

  • STM: Sijil Teknologi Maklumat
  • SLK: Sijil Perkhidmatan Logistik
  • UPA: Unit Pengajian Am

1.3 Aliran Kerja Pengesahan Jadual (Approval Workflow)

1
Draf Program
Penyelaras STM/SLK/UPA menyusun slot & subjek.
2
Penyelaras Induk
Semakan silang bilik, pensyarah & pertindihan.
3
Kelulusan TPA
Pengesahan oleh Timbalan Pengarah Akademik.
4
Terbit (Live)
Jadual berstatus rasmi & dipaparkan kepada umum.

2. Panduan Penggunaan Mengikut Peranan

2.1 Panduan untuk Pelajar (Portal Pelajar)

  1. Buka alamat laman web: https://sijawap.netlify.app/pelajar atau klik butang Portal Pelajar di laman utama.
  2. Pilih Program Pengajian anda (contohnya: Sijil Teknologi Maklumat - STM).
  3. Pilih Kelas / Semester anda (contohnya: STM 1 atau SLK 2).
  4. Sistem akan memaparkan jadual waktu mingguan secara automatik merangkumi masa mula, masa tamat, kod kursus, nama pensyarah, dan lokasi bilik kuliah / makmal.
  5. Muat Turun / Cetak: Klik butang "Cetak Jadual" atau "Simpan PDF" untuk menyimpan salinan ke telefon pintar atau komputer anda.

2.2 Panduan untuk Pensyarah (Portal Pensyarah)

  1. Layari https://sijawap.netlify.app/pensyarah.
  2. Pilih nama atau singkatan pensyarah anda dari menu senarai susur (*dropdown*).
  3. Ciri Jadual Peribadi: Sistem akan menapis dan hanya memaparkan kelas yang diajar oleh anda sepanjang minggu berserta jumlah jam kredit.
  4. Semakan Kekosongan Bilik: Buka tab "Semak Bilik" untuk melihat bilik kuliah, bengkel, atau makmal komputer yang tidak berpenghuni pada slot waktu tertentu bagi tujuan kelas gantian.
  5. Hebahan Program: Pensyarah boleh memasukkan nota atau pengumuman penting berkaitan kelas untuk dilihat oleh pelajar.

2.3 Panduan untuk Pentadbir / Programmer (Portal Admin)

Portal Programmer (Programmer.html) merupakan pusat pengurusan konfigurasi sistem jadual.

A. Pengurusan Sesi Semester

  • Tetapkan sesi aktif semasa (contohnya: SESI 1 2026/2027).
  • Tetapkan tarikh kuat kuasa jadual untuk dipaparkan pada nota kaki (*footer*) cetakan rasmi.

B. Pengurusan Templat Excel (Muat Naik Berkelompok / Bulk Upload)

Sistem menyediakan fail templat Excel standard dalam folder templates/:

Fail Templat Lokasi Fail Kandungan Data
Template_Pelajar.xlsx templates/Template_Pelajar.xlsx Nama pelajar, No. Matrik, Program, Semester, Sesi.
Template_Pensyarah.xlsx templates/Template_Pensyarah.xlsx Nama penuh pensyarah, Nama Singkatan (cth: CND), Jabatan, Emel.
Template_Subjek.xlsx templates/Template_Subjek.xlsx Kod kursus, Nama kursus, Jam kredit, Jam kuliah/amali.
PENTING: Peraturan Mengisi Templat Excel
Jangan ubah susunan atau nama lajur (*header*) dalam fail templat Excel tersebut. Pastikan singkatan nama pensyarah dan kod kursus adalah konsisten dengan data yang didaftarkan dalam sistem.

C. Pengesanan Pertindihan Jadual (Clash Detection)

Sistem dilengkapi dengan enjin semakan pintar yang mengesan secara automatik:

  • Pertindihan Pensyarah: Pensyarah yang sama dijadualkan mengajar 2 kelas berbeza pada masa yang sama.
  • Pertindihan Bilik / Lokasi: Lokasi makmal/bilik yang sama digunakan serentak oleh 2 kumpulan kelas.
  • Pertindihan Kelas Pelajar: Kelas pelajar yang sama mempunyai 2 subjek bertindih.

4. Panduan Deployment & Penerbitan

Terdapat dua cara untuk memuat naik perubahan yang anda lakukan ke laman web langsung (*live*): Kaedah 1 (Automatik) dan Kaedah 2 (Manual).

4.1 Kaedah Automatik (Paling Pantas)

Anda telah dibekalkan dengan skrip pelancar yang telah dikonfigurasikan:

  1. Untuk Kemaskini GitHub & Netlify:

    Klik dua kali fail DEPLOY.bat. Masukkan nota ringkas perubahan anda (contoh: kemaskini subjek sesi 1) dan tekan Enter. Skrip akan memuat naik fail ke GitHub secara automatik dan Netlify akan mengemaskini laman web dalam masa 1 minit.

  2. Untuk Kemaskini Firebase Hosting:

    Klik dua kali fail firebase-deploy.bat. Log masuk melalui pelayar jika diminta, dan skrip akan terus memuat naik fail terkini ke Firebase Hosting.

4.2 Panduan Deployment Manual (Langkah demi Langkah untuk Beginner)

Jika anda ingin menjalankan setiap arahan secara manual melalui Terminal / Command Prompt, ikuti 5 langkah terperinci berikut:

Cara Membuka Terminal
Di dalam VS Code, tekan kombinasi kekunci Ctrl + ~ atau buka menu atas: Terminal > New Terminal. Pastikan laluan berada pada folder projek: C:\Users\User\Downloads\jadual-waktu-kkpps-main.

Langkah 1: Semak Status Fail yang Diubah

Sebelum menghantar fail, lihat senarai fail yang telah anda sunting atau tambah:

git status

Fail berwarna merah menunjukkan fail yang telah disunting atau fail baharu yang belum didaftarkan.

Langkah 2: Daftarkan Semua Fail (Git Add)

Jalankan arahan berikut untuk mendaftarkan semua fail terkini:

git add -A

Jika anda jalankan git status semula, nama fail kini bertukar menjadi hijau.

Langkah 3: Cipta Mesej Catatan (Git Commit)

Simpan perubahan tersebut bersama catatan ringkas tentang apa yang telah anda ubah:

git commit -m "kemaskini jadual waktu dan modul terkini"

Langkah 4: Hantar Kod ke GitHub & Netlify (Git Push)

Hantar fail yang telah di-commit ke repositori GitHub cawangan main:

git push origin main
Auto-Deploy Netlify Berfungsi!
Sebaik sahaja arahan git push origin main berjaya, pelayan Netlify akan mengesan kod baharu secara automatik. Dalam masa 60 hingga 120 saat, laman https://sijawap.netlify.app/ akan dikemaskini tanpa perlu sebarang tindakan manual tambahan!

4.3 Manual Deployment ke Firebase Hosting

Netlify dikemaskini melalui GitHub, manakala Firebase Hosting menggunakan Firebase CLI. Ikuti langkah berikut untuk memuat naik ke Firebase Hosting:

Langkah 1: Semak Status Log Masuk Firebase

firebase login:list

Jika tertera "No authorized accounts", teruskan ke Langkah 2.

Langkah 2: Log Masuk Akaun Google Firebase

firebase login
  1. Sistem akan membuka pelayar web (Chrome / Edge).
  2. Pilih akaun Google yang mempunyai akses kepada projek Firebase SiJAWAP.
  3. Klik butang "Allow" / "Izinkan".
  4. Terminal akan memaparkan mesej hijau: ✔ Success! Logged in as emel@gmail.com.

Langkah 3: Tetapkan Projek Firebase Aktif

firebase use sistem-jadual-waktu-kkpps

Langkah 4: Terbitkan Fail ke Hosting

firebase deploy --only hosting

Hasil yang berjaya akan memaparkan:

✔  Deploy complete!

Project Console: https://console.firebase.google.com/project/sistem-jadual-waktu-kkpps/overview
Hosting URL: https://sistem-jadual-waktu-kkpps.web.app

Langkah 5 (Tambahan): Kemaskini Peraturan Keselamatan Pangkalan Data

Sekiranya anda membuat perubahan pada fail firebase-rules.json, jalankan:

firebase deploy --only database

5. Penyelesaian Masalah (Troubleshooting & FAQ)

5.1 Ralat: "No authorized accounts" / "Failed to authenticate"

Punca Sesi token Firebase CLI telah tamat tempoh atau belum dilog masuk pada komputer semasa.
Penyelesaian Jalankan arahan firebase login --reauth dalam terminal, atau klik fail firebase-deploy.bat untuk log masuk semula melalui pelayar web.

5.2 Perubahan Sudah Di-deploy tetapi Laman Web Masih Papar Versi Lama

Punca Pelayar web menyimpan cache lama atau Service Worker (PWA) sedang menyimpan versi luar talian (*offline*).
Penyelesaian
  1. Lakukan Hard Refresh: Tekan kekunci Ctrl + F5 (atau Ctrl + Shift + R) pada papan kekunci pelayar.
  2. Di telefon pintar: Buka tetapan pelayar > Clear Browsing Data / Kosongkan Cache, kemudian muat semula halaman.

5.3 Ralat Git: "Updates were rejected because the remote contains work..."

Punca Terdapat perubahan baharu di GitHub yang belum dimuat turun ke komputer anda sebelum anda cuba tolak (*push*).
Penyelesaian Tarik perubahan terkini dari GitHub terlebih dahulu dengan arahan: 
git pull origin main --rebase
Kemudian lakukan git push origin main sekali lagi.

5.4 Ralat Ralat Format Semasa Muat Naik Fail Excel

Punca Lajur atau susunan tajuk fail Excel tidak mematuhi skema templat sistem SiJAWAP.
Penyelesaian Gunakan templat bersih yang disediakan di dalam folder templates/:
  • templates/Template_Pelajar.xlsx
  • templates/Template_Pensyarah.xlsx
  • templates/Template_Subjek.xlsx
Salin data anda ke dalam templat tersebut tanpa mengubah tajuk lajur baris pertama.
